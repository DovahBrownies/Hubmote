# Security policy

**Reporting a vulnerability:** please use GitHub's private reporting (the
repository's **Security** tab, then **Report a vulnerability**; it needs a
GitHub account), not a public issue. Say what you found, how to reproduce
it, and which firmware or companion version you used. If that button isn't
there, open an issue asking for a private contact, without any details.
You'll get an answer as soon as possible; this is a hobby project, so
please allow a few weeks for a fix.

**Supported versions:** the latest release of the firmware and of the
companion app (0.6 or later: earlier versions lack the pairing lockout and
request limits, and 0.3 and older answer anyone on the network).

What Hubmote protects against, and what it doesn't, is described in
[docs/security.md](docs/security.md). Its "Known gaps" are known already:
no need to report them, but ideas for closing them are welcome.
