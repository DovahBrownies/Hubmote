Install Hubmote

Puts the remote's firmware on a Waveshare ESP32-S3 touch screen board straight from this page. Use Chrome or Edge on a computer.

  1. 1

    Pick your board

    Nobody has run Hubmote on this board yet: its support follows Waveshare's documentation and demo code. Whether it works or not, please tell us in an issue on GitHub.

  2. 2

    Connect the board

    Plug its USB port (the USB-C socket marked USB, not UART) into this computer with a data cable.

  3. 3

    Install

    Click Install, pick the port called USB JTAG/serial debug unit (on Windows it may show as USB Serial Device (COMn)), then Install Hubmote for your board.

    If it can't connect, close the message and click Install again. Still failing: unplug the board, hold its BOOT button while plugging it back in, let go, then Install.

    This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.

    Installing only works from an https page or from localhost.
  4. 4

    Erase, or keep what's on it

    For a new remote, tick Erase device. To update one you already use, leave it unticked: its pairing, Wi-Fi, learned remotes and settings stay. Then Next and Install, and keep this page open until it finishes, about two minutes.

  5. 5

    Set it up on the remote

    If the board sits upside down (as the 7B does in its 3D-printed case), first tap the gear (top right) > Screen > Rotate 180°, then Done.

    The remote prepares its pairing key (up to a minute), asks for your Wi-Fi network and lists the Google TVs it finds: tap yours, then type the code the TV shows.

Already have a remote set up? Update it over Wi-Fi instead: on the remote, Settings > About, then Check and Install. It keeps your pairing and settings.

The companion app for the Streamer (optional: the TV's own apps on the remote, and typing in any app): companion.apk. How to install it: the companion guide.
