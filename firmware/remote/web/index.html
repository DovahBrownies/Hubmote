Install Hubmote

This page puts Hubmote's firmware, the software that runs the remote, on a Waveshare ESP32-S3 touch screen board. Use Chrome or Edge on a computer.

  1. 1

    Pick your board

    Nobody has run Hubmote on this board yet. Its support is based on Waveshare's documentation and demo code. Whether it works or not, please tell us in an issue on GitHub.

  2. 2

    Connect the board

    Plug the board's USB port into this computer with a USB-C cable that carries data, not one that only charges. If the board has two ports, use the one marked USB, not UART.

  3. 3

    Install

    Click Install and pick the port called USB JTAG/serial debug unit. On Windows it may show as USB Serial Device (COMn), where n is a number. Then click Install Hubmote for your board.

    If it can't connect, close the message and click Install again. If it still fails, unplug the board. Hold its BOOT button while you plug it back in, let go, then click Install.

    This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.

    Installing only works from an https page or from localhost.
  4. 4

    Erase, or keep what's on it

    For a new remote, tick Erase device. To update a remote you already use, leave it unticked, and its pairing, Wi-Fi, learned remotes and settings stay. Then click Next and Install. Keep this page open until it finishes, which takes about two minutes.

  5. 5

    Set it up on the remote

    If the board sits upside down, as the 7B does in its 3D-printed case, turn the screen first. Tap the gear at the top right, then Screen > Rotate 180°, then Done.

    The remote first prepares its pairing key, which can take up to a minute. Then it asks for your Wi-Fi network and lists the Google TVs it finds. Tap yours, type the code the TV shows, and tap Pair.

Already have a remote set up? You can update it over Wi-Fi instead. On the remote, open Settings > About, then tap Check and Install. It keeps your pairing and settings.

The optional companion app for the Streamer shows the TV's own apps on the remote and lets you type into any app. Download it here: companion.apk. To install it, follow the companion guide.
